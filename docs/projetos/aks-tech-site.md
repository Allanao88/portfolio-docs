# AKS - Tech | Site Institucional

[Visitar o site institucional](https://akstech.vercel.app/){ .md-button .md-button--primary }

## Visão geral

Desenvolvimento do site institucional da AKS - Tech, com foco na apresentação da empresa, na comunicação dos serviços e na construção de uma presença digital consistente com sua identidade visual.

O projeto integra a frente institucional da empresa ao desenvolvimento de produtos digitais e soluções de tecnologia.

## Objetivos do projeto

- Apresentar a identidade e a proposta de valor da AKS - Tech.
- Organizar a comunicação dos serviços oferecidos.
- Construir uma interface responsiva e coerente com a marca.
- Criar uma base evolutiva para futuras melhorias no site.

## Implementação técnica

O desenvolvimento utiliza tecnologias modernas de front-end:

- **React:** composição da interface por componentes reutilizáveis.
- **TypeScript:** tipagem estática para facilitar manutenção e reduzir erros.
- **Vite:** ambiente de desenvolvimento e empacotamento da aplicação.
- **CSS e interface responsiva:** aplicação da identidade visual em diferentes tamanhos de tela.
- **Vercel:** publicação da aplicação web.

## Decisões de engenharia

A organização por componentes permite evoluir partes da interface sem concentrar toda a implementação em um único arquivo. A separação entre apresentação, estrutura e estilos também facilita a manutenção e a investigação de problemas.

A identidade visual utiliza uma base escura, contrastes claros e verde-limão como cor de destaque, buscando consistência entre o site institucional e os produtos digitais da empresa.

## Competências demonstradas

- Desenvolvimento de interfaces web.
- Organização de componentes reutilizáveis.
- Aplicação de identidade visual em produto digital.
- Uso de TypeScript e ferramentas modernas de desenvolvimento.
- Publicação e manutenção de aplicações web.
