# Portfólio MkDocs — Allan Augusto

## Como usar

1. Copie o conteúdo de `docs/` para o repositório atual do portfólio.
2. Substitua o `mkdocs.yml` pelo arquivo deste pacote.
3. Instale/atualize o Material for MkDocs:
   `pip install -U mkdocs-material`
4. Teste localmente:
   `mkdocs serve`
5. Gere o site:
   `mkdocs build --strict`

## Observação

Os arquivos dos cases existentes foram mantidos como placeholders neste pacote.
Substitua o conteúdo deles pelos seus textos atuais para preservar os detalhes técnicos já publicados.
